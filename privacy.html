개인정보처리방침

적용 대상: 연락함의 개인용 Windows 앱과 선택적 Gmail 수집 구성. 시행일: 2026년 10월 25일.

처리하는 정보와 목적

사용자가 연결한 Google 계정의 이메일 주소, 메일 식별자·대화 식별자, 발신자·수신자, 제목·본문, 수신 시각, 라벨, 첨부파일 이름을 처리합니다. 선택한 연락을 표시하고, 업무 요청·정보 변경 후보와 후속 조치를 정리하기 위해 사용합니다. 자동 분류를 위해 첨부파일 내용을 내려받지는 않습니다.

Google 권한

  • Gmail 읽기: 메일과 연결 계정을 확인합니다.
  • Gmail 발송: 별도 연결에서 사용자 확인 후 답장을 보냅니다. 자동 수집 연결에는 발송 권한이 없습니다.
  • Drive 읽기: 무료 수집 연결에서 지정된 비공개 결과 파일과 소유자·공유 상태를 읽습니다. Google의 권한 자체는 Drive 전체 읽기를 허용할 수 있지만 앱은 설정된 수집 결과 파일만 조회합니다.

계정 소유자의 별도 Google Apps Script 수집기는 승인받은 권한으로 Gmail을 읽고 같은 계정의 수집 결과 파일을 작성합니다. 데스크톱 읽기 연결과 별개의 구성입니다.

저장과 보관

PC에서는 연결 정보와 Gmail 수집 결과·처리 상태를 Windows 사용자에 연결된 보호 저장소에 보관합니다. 무료 수집 결과는 계정 소유자의 비공개 Google Drive에도 저장됩니다. 이 Drive 파일은 앱 자체 암호화가 추가된 파일이 아니며 Google 계정의 접근 통제로 보호됩니다.

무료 수집 파일은 최근 30일의 후보를 유지하도록 처리합니다. PC로 가져온 기록은 별도로 보관되며, 수집 중지나 Google 접근 철회만으로 기존 저장 기록이 삭제되지는 않습니다. 용량 한도에 도달하면 수집이 중지될 수 있습니다.

공유와 이용 제한

메일 내용과 인증정보를 이 공개 안내 사이트나 공개 소스 저장소에 게시하지 않습니다. 현재 Gmail 업무 후보 분류는 규칙 기반으로 처리하며 외부 AI 학습을 위해 메일을 제공하지 않습니다. Google 사용자 데이터를 판매하거나 광고 목적으로 이용하지 않습니다. Google API에서 받은 정보의 이용·이전은 Google API Services User Data Policy의 Limited Use 요구 사항을 따릅니다.

안내 사이트 방문 기록

이 안내 사이트는 GitHub Pages에서 제공합니다. GitHub는 보안 목적으로 방문자의 IP 주소를 기록할 수 있습니다. 이 안내 사이트에는 별도의 광고·분석 스크립트를 넣지 않습니다. GitHub 개인정보처리방침을 참고해 주세요.

중지·철회·삭제

앱의 수집 중지는 PC의 가져오기를 중지합니다. PC가 꺼져도 실행되는 무료 수집을 중지하려면 별도의 Google Apps Script 예약 수집도 중지해야 합니다. Google 계정의 연결된 앱 관리에서 접근 권한을 철회할 수 있습니다.

기존 저장 데이터 삭제는 수집 중지와 별개입니다. 필요한 자료를 보관한 뒤 앱의 해당 수집 범위 삭제 기능과 Google Drive의 수집 결과 파일 삭제를 각각 사용합니다. 저장된 데이터의 범위 확인이나 삭제 지원은 아래 문의 주소로 요청할 수 있습니다.
